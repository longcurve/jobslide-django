JobReacher is a job application tracking software, written in Python using Django Web Development framework. The idea is to track all relevant information related to a job application, including any applicable resume used, or to be used to apply.

  • Date application was submitted (if applicable)
  • Company Name
  • Company Location
  • Company contact information
  • Application Status (Applied, Interviewing)
  • Position of interest (if applicable)
  • Minimum and Maximum Salary (if applicable)

JobReacher is still under the "alpha" stage of development.
